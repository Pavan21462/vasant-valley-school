# Vasant Valley School Website

## Project Overview

This project is a modern redesign of the Vasant Valley School website developed as part of the Dettroin Full Stack Developer Internship Assignment.

The website is designed using modern UI principles with a clean layout, responsive design, smooth scrolling navigation, reusable React components, and interactive sections.

## Installation

Clone the repository

```bash
git clone https://github.com/Pavan21462/vasant-valley-school.git
```

Go to project folder

```bash
cd vasant-valley-school
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

---

## Build

```bash
npm run build
```
